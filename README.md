## 🏃 Running Locally

Want to run or tweak this on your own machine? It’s completely zero-config:

1. **Clone the repo:**
   ```bash
   git clone https://github.com/Divyansh-co/DIV-PORTFOLIO--.git
   cd DIV-PORTFOLIO--
   ```

2. **Open the website:**
   - Simply double-click `index.html` to open it in your favorite browser (Chrome, Edge, Firefox, Brave, Safari).
   - *Or* run a lightweight local server:
     ```bash
     # Using Python
     python -m http.server 3000
     ```
   - Open `http://localhost:3000` in your browser.
